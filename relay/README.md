# Nexterm 远程访问中继

在手机或任意电脑的浏览器上查看、操作电脑上 Nexterm 已打开的标签页：画面实时同步，可以输入，也可以临时让终端改用手机的尺寸。同一个中继也承载**会话分享**：把单个终端通过一次性链接分享给别人。

```
浏览器 / PWA     ──wss──▶  中继服务器（本目录）  ◀──wss──  Nexterm（电脑）
            └──────────── AES-256-GCM 端到端加密 ────────────┘
```

- **中继看不到内容**：配对密钥放在二维码链接的 `#` 后面，浏览器不会把它发给服务器。中继只知道由密钥算出的房间号，转发的都是密文。
- 每次连接时双方各出一个随机数派生新会话密钥；帧带递增序号，中继无法重放、丢弃或调换帧。
- 电脑主动连出去，不需要公网 IP，也不用开放端口。

## 部署（Docker + 自备 HTTPS 反向代理）

中继容器只监听本机 `127.0.0.1:7085`，需要你自己的反向代理（Nginx 等）提供 HTTPS 并转发到它（含 WebSocket）。浏览器只在 HTTPS 下提供加密 API，所以必须走 HTTPS。

```bash
cp .env.example .env
#   HOST_TOKEN=$(openssl rand -hex 24)
docker compose up -d --build --remove-orphans
```

也可以只跑中继（`docker build -t wtn-relay . && docker run -d -p 127.0.0.1:8080:8080 -e HOST_TOKEN=... wtn-relay`），再反向代理过去，记得转发 WebSocket：

```nginx
location / {
    proxy_pass http://127.0.0.1:8080;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_read_timeout 120s;
}
```

不用 Docker：`npm ci --omit=dev && PORT=8080 HOST_TOKEN=... node server.js`（Node ≥ 20）。

### 更新

把新版的 `server.js`、`package*.json` 和 `public/` 覆盖到部署目录（`.env` 保留不动），再 `docker compose up -d --build`。电脑端新功能可能需要新版页面，例如会话分享需要 `public/share.html`。

服务器访问不了 Docker Hub 时，只要本机已有 `node:22-alpine` 镜像，就可以离线构建：

```bash
DOCKER_BUILDKIT=0 docker build --pull=false -t nexterm-relay-relay .
docker compose up -d --no-build
```

镜像名是 `<compose 项目名>-relay`，项目名默认就是目录名。

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `8080` | 监听端口 |
| `HOST` | `0.0.0.0` | 监听地址 |
| `HOST_TOKEN` | 空 | 设置后，只有带这个令牌的电脑才能注册为主机。建议设置，防止别人借用你的中继。 |

## 使用

1. Nexterm → 设置 → **远程访问**：勾选开启，填写中继地址（如 `https://relay.example.com:8443`）和主机令牌，保存。
2. 状态变成"已连接中继服务器"后，用手机相机扫描设置页里的二维码，或复制配对链接在电脑浏览器中打开。
3. 在手机浏览器里选择"添加到主屏幕"，以后可以像 App 一样直接打开。

远程端：

- 标签列表包含电脑上所有窗口的标签页，点开即可实时查看。
- 底部工具栏：Esc / Tab / Ctrl / Alt（粘滞键）/ 方向键 / ^C 等，⌨ 打开系统键盘。
- **接管尺寸**：把电脑上这个标签的终端改成远程屏幕的行列数（vim、htop 等全屏程序在手机上更好用）。点"还给电脑"、返回列表或断开连接都会恢复；电脑上标签右下角会显示蓝色徽章，点它也能收回。
- A- / A+ 调整字号。电脑尺寸比远程屏幕大时可以左右、上下滑动查看，有新输出时会自动跟随光标。
- **登录与重连**：标签页等待输入用户名 / 密码、或首次连接要确认主机密钥时，远程端会直接弹出对应的表单，提交后电脑上的对话框同时关闭。连接失败或会话结束时可以在远程端重新连接，密码认证的 SSH 会话还能重新输入密码。
- **多台电脑**：一台设备可以配对多台电脑（每台电脑扫一次码，或点首页右上角 ＋ 粘贴链接），首页列出所有电脑，它们同时保持连接，各自独立加密。不同电脑可以用不同的中继服务器。
- **会话管理**：电脑详情页的「会话」分页列出电脑上保存的会话，可以新建、编辑、复制、删除，或者直接在电脑上打开（打开后自动进入新标签页）。远程端只编辑常用字段（主机、端口、用户名、认证、启动命令等），跳板机、代理、隧道等其它选项保存时保留原值；串口和自定义协议的会话只能在电脑上编辑。远程端看不到已保存的密码。
- **文件管理**：「文件」分页选择一个已连接的 SSH 标签页，浏览它的远程文件；可以下载到本设备（最大 1 GB）、从本设备上传、新建文件夹、重命名、删除。传输经过同一条加密链路，带流量控制。

安全相关：

- 二维码和配对链接就是钥匙，只在自己的设备上打开。如果泄露了，在设置页点**重新生成**，所有已配对的设备都会失效。
- 设置页列出当前连接的设备，可以单独断开。
- 勾选"远程设备只能查看"后，远程端不能输入、不能接管尺寸，也不能修改会话、上传或删除文件（仍可浏览和下载）。
- 最多同时连接 8 台设备。

## 会话分享

只要填写了中继地址（不需要开启远程访问），就可以在标签或窗格的右键菜单选「分享此会话…」，为这一个终端生成链接 `https://中继/s#k=…`。

- 每个分享有自己的密钥和房间，只保存在内存里；停止分享、关闭标签、到期或退出 Nexterm 后链接永久失效。访客看不到其它标签、会话、文件和登录表单。
- 访客打开链接、填一个名字就能加入，页面按浏览器语言显示中文或英文。电脑端的分享对话框列出访客，可以授予 / 收回控制、移出，或允许 / 拒绝加入；有请求时窗格上方会出现横幅。
- 访客默认只读，可以点「申请控制」，由电脑端授权；同一时间只有一位访客能输入，电脑这边的键盘不受影响。有控制权的访客还可以「接管尺寸」，把电脑上的终端改成自己窗口的行列数；交还或被收回控制、断线、被移出、分享结束时自动还给电脑，电脑上点窗格右下角的蓝色徽章也能收回。
- 可选：有效期（1 / 4 / 24 小时或直到停止）、包含回滚历史（默认只发送当前屏幕）、新访客需确认、单人链接。被放行的访客断线后可以直接回来，不用再确认。
- 每个分享最多 8 位访客，同时最多 4 个分享。
- 需要中继版本包含 `public/share.html`；旧版中继创建分享时会提示更新。

## 开发

```bash
npm install
npm start            # http://localhost:8080
npm test             # 中继 + 加密协议测试（node:test）
```

`node dev/fake-share-host.mjs` 启动本地中继和一个模拟分享，打印出的链接可以直接在浏览器里试分享页。

局域网测试可以填 `http://<电脑IP>:8080`，但浏览器在非 HTTPS 页面上通常不提供 WebCrypto（`localhost` 除外），所以实际使用必须走 HTTPS。

协议说明见 `server.js` 和 `public/crypto.js` 开头的注释；电脑端实现在 `src-tauri/src/remote.rs`、`share.rs`、`relay_link.rs`、`remote_crypto.rs`，两边的加密实现由 `remote_crypto.rs` 里的跨语言测试向量保证一致。
